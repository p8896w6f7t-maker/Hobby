변환 방식
1. 원본 XNB를 읽습니다.
2. XNB 내부의 Texture2D와 JSON 헤더를 추출합니다.
3. 기존 PNG만 새 PNG로 교체합니다.
4. JSON 헤더는 그대로 유지합니다.
5. 새 XNB를 생성합니다.

생성 방식은 비압축 XNB입니다.

xnb.js는 XNB의 압축 해제를 지원하고, 패킹에서는 비압축과 LZ4를 지원합니다. LZX 패킹은 지원하지 않습니다.
